# Musiques de réveil (optionnel)

Déposez ici des fichiers MP3 pour remplacer les mélodies synthétiques :

- `serene-morning.mp3`
- `acoustic-dawn.mp3`
- `lofi-glow.mp3`
- `soft-piano.mp3`
- `sunny-day.mp3`

Si un fichier est présent, il sera utilisé automatiquement à la place de la mélodie générée.

## 🎬 Template 4 : Script Vidéo (30 secondes)

### Script détaillé

```
[0-3s]   : [Écran noir] "Vous voulez télécharger des vidéos YouTube ?"
[3-6s]   : [Capture MeTube] "MeTube vous permet de le faire gratuitement"
[6-10s]  : [Démo rapide] "Collez l'URL, choisissez le format, téléchargez"
[10-15s] : [Avantages] "Sans logiciel, sans publicité, 100% privé"
[15-20s] : [Offre] "100 crédits offerts pour commencer"
[20-25s] : [CTA] "Essayez maintenant sur iahome.fr"
[25-30s] : [Logo] "MeTube - Téléchargeur YouTube privé"
```

### Musique
- **Style** : Énergique mais professionnel
- **Durée** : 30 secondes
- **Volume** : Pas trop fort (pour ne pas gêner)

### Textes à l'écran
- **Taille** : Grande (lisible sur mobile)
- **Couleur** : Blanc sur fond sombre ou vice versa
- **Durée** : 3-4 secondes par texte

## 📝 Checklist de création

### Pour chaque créatif
- [ ] Format correct (1080x1080 ou 1200x628)
- [ ] Texte lisible (grande police)
- [ ] CTA visible et clair
- [ ] Couleurs cohérentes avec la marque
- [ ] Pas trop de texte (règle des 20%)
- [ ] Testé sur mobile (prévisualisation)

### Pour les vidéos
- [ ] Durée : 15-60 secondes
- [ ] Format : MP4, 1080p minimum
- [ ] Audio : Musique ou voix-off
- [ ] Sous-titres : Recommandés (80% regardent sans son)
- [ ] CTA : Visible dans les 3 premières secondes

---

## 🎯 Recommandations par objectif

### Objectif : Maximiser les clics
- **Format** : Vidéo (meilleur CTR)
- **Texte** : Court et accrocheur
- **CTA** : "Essayer maintenant"

### Objectif : Maximiser les conversions
- **Format** : Image simple avec avantages clairs
- **Texte** : Focus sur les bénéfices
- **CTA** : "S'inscrire gratuitement"

### Objectif : Éduquer l'audience
- **Format** : Carrousel (plus d'informations)
- **Texte** : Explications détaillées
- **CTA** : "En savoir plus"

## 💡 Conseils créatifs

1. **Testez toujours 2-3 variantes** : Vous ne savez jamais ce qui va marcher
2. **Utilisez des couleurs vives** : Rouge, orange, vert attirent l'attention
3. **Montrez le produit** : Capture d'écran de MeTube si possible
4. **Texte court** : Maximum 125 caractères pour le texte principal
5. **CTA clair** : "Essayer maintenant" > "Cliquez ici"
6. **Mobile-first** : 80% des utilisateurs Facebook sont sur mobile

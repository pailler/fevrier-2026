## 📊 Recommandations pour les campagnes Facebook

### 1. Formats recommandés

**Pour la notoriété :**
- Image carrée (1080x1080px) ou vidéo courte (15-30s)
- Texte accrocheur avec emojis
- CTA : "En savoir plus"

**Pour les conversions :**
- Carrousel (5-10 images) montrant les différents services
- Vidéo démo (30-60s)
- CTA : "Essayer gratuitement" ou "Créer un compte"

**Pour l'engagement :**
- Vidéo avec question
- Image avec texte engageant
- CTA : "Commenter" ou "Partager"

### 2. Budget recommandé

**Test initial :**
- 5-10€/jour par campagne
- Tester 2-3 versions différentes
- Durée : 3-7 jours

**Optimisation :**
- Augmenter le budget sur les meilleures performances
- Arrêter les campagnes avec mauvais ROI
- Budget idéal : 20-50€/jour pour une campagne active

### 3. Ciblage recommandé

**Audiences personnalisées :**
- Visiteurs du site (retargeting)
- Personnes ayant liké la page
- Lookalike audiences (1-3%)

**Intérêts :**
- Intelligence Artificielle
- OpenAI
- Productivité
- Outils professionnels
- Freelance
- Entrepreneuriat

**Comportements :**
- Acheteurs en ligne
- Early adopters
- Utilisateurs de services SaaS

### 4. Timing optimal

**Meilleurs jours :**
- Mardi, Mercredi, Jeudi

**Meilleures heures :**
- 9h-12h (matin)
- 18h-21h (soir)

**Éviter :**
- Lundi matin
- Vendredi après-midi
- Week-end (sauf si ciblage loisirs)

### 5. Métriques à suivre

**Notoriété :**
- Portée (Reach)
- Impressions
- Taux d'engagement

**Conversions :**
- CPC (Coût par clic)
- CTR (Taux de clic)
- CPA (Coût par acquisition)
- Taux de conversion

**Engagement :**
- Likes
- Commentaires
- Partages
- Sauvegardes

### 6. A/B Testing recommandé

**Tester :**
- Différents titres
- Différents textes
- Différentes images/vidéos
- Différents CTAs
- Différentes audiences

**Durée :**
- Minimum 3 jours par test
- Budget minimum : 50€ par variante

   - Texte : "À partir de 4,99€"

   - Design accrocheur avec le nombre "200"

   - Texte : "200 crédits GRATUITS"

   - Carrousel avec une image par service
   - Design cohérent
   - Texte : "Découvrez nos services"

### Vidéos recommandées

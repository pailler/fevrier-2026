🎴 Cartes Lovelace

Les cartes Lovelace sont les éléments visuels de votre interface Home Assistant. Elles permettent d'afficher et de contrôler vos entités (lumières, capteurs, interrupteurs, etc.) de manière élégante et personnalisée.

Comment les utiliser :

  1. Copiez le code YAML de la carte qui vous intéresse
  2. Dans Home Assistant, allez dans Paramètres → Tableaux de bord → Lovelace
  3. Cliquez sur les 3 points (⋮) en haut à droite → Modifier le tableau de bord
  4. Cliquez sur + Ajouter une carte → Code éditeur
  5. Collez le code YAML et adaptez les noms d'entités (ex: light.salon → light.votre_lumiere)
  6. Cliquez sur Sauvegarder

🔧 Templates

Les templates sont des capteurs ou entités calculés dynamiquement à partir d'autres entités. Ils permettent de créer des données personnalisées, des calculs, ou des conditions complexes.

Comment les utiliser :

  1. Copiez le code template (section Templates & Automations)
  2. Dans Home Assistant, allez dans Paramètres → Appareils et services → Helpers
  3. Ou éditez directement le fichier configuration.yaml dans le dossier config
  4. Ajoutez le code dans la section template:
  5. Redémarrez Home Assistant ou rechargez les templates via Paramètres → Appareils et services → Template → Recharger

🔌 Intégrations

Les intégrations permettent de connecter Home Assistant à des appareils, services et plateformes externes (caméras, capteurs, assistants vocaux, services météo, etc.). Elles étendent les capacités de votre installation Home Assistant.

Comment les utiliser :

  1. Dans Home Assistant, allez dans Paramètres → Appareils et services
  2. Cliquez sur + Ajouter une intégration en bas à droite
  3. Recherchez l'intégration souhaitée dans la liste ou utilisez la barre de recherche
  4. Suivez les instructions de configuration (saisie d'identifiants, autorisations, etc.)
  5. Une fois configurée, l'intégration apparaîtra dans Appareils et services avec ses entités
  6. Vous pourrez ensuite utiliser ces entités dans vos cartes Lovelace, templates et automatisations

Astuce : Certaines intégrations nécessitent une configuration via le fichier configuration.yaml. Consultez la documentation officielle de Home Assistant pour les détails spécifiques à chaque intégration.

Comment utiliser les automatisations

Les automatisations permettent d'automatiser des actions en fonction de conditions (ex: allumer la lumière quand il fait nuit, envoyer une notification si une porte s'ouvre, etc.).

Comment les utiliser :

  1. Copiez le code d'automation ci-dessus
  2. Dans Home Assistant, allez dans Paramètres → Automatisations et scènes → Automatisations
  3. Cliquez sur + Créer une automatisation → Créer une nouvelle automatisation
  4. Cliquez sur les 3 points (⋮) → Modifier en YAML
  5. Collez le code YAML et adaptez les entités selon vos besoins
  6. Cliquez sur Sauvegarder

🔍 Découvrir d'autres automatisations (hadiscover)

hadiscover indexe les automatisations Home Assistant partagées par la communauté depuis les dépôts GitHub avec le topic hadiscover. Vous pouvez y rechercher des automatisations par nom, déclencheur ou action.

Comment les ajouter à Home Assistant :

  1. Copier le YAML — Cliquez sur le lien GitHub d'une automatisation et copiez le code YAML.
  2. Ouvrir Home Assistant — Paramètres → Automatisations et scènes → Créer une automatisation.
  3. Coller le code — Menu 3 points (⋮) → Modifier en YAML, puis collez votre code.
  4. Adapter — Modifiez les noms d'entités et paramètres selon votre installation.
  5. Enregistrer — Sauvegardez et testez l'automatisation.

Vous partagez vos automatisations ? Ajoutez le topic hadiscover à votre dépôt GitHub pour les faire découvrir à la communauté.

📘 Blueprints — HA Blueprint Hub

Découvrez, partagez et importez des blueprints (modèles d'automatisation réutilisables) pour Home Assistant. Le HA Blueprint Hub référence plus de 170 blueprints créés par la communauté, répartis en plusieurs catégories (contrôle d'appareils, notifications, boutons et télécommandes, etc.).

  • 🎛️ Contrôle d'appareils — ex. lumière activée au mouvement
  • 🔔 Notifications — ex. alerte quand une personne quitte une zone
  • 🔘 Actions sur boutons — télécommandes IKEA, Philips Hue, SONOFF, Xiaomi Aqara…

Comment importer un blueprint : sur le site, choisissez un blueprint puis cliquez sur Import pour obtenir l’URL ou les instructions d’import dans Home Assistant (Paramètres → Automatisations et scènes → Blueprints).

1. Introduction et accès gratuit (0:00 – 0:45)

Bonjour à tous !

Dans cette vidéo, je vous présente les dernières nouveautés de la plateforme IA Home pour Home Assistant. Et avant d'entrer dans le vif du sujet : un petit rappel important.

Les ressources Home Assistant — manuels, codes Lovelace, automatisations — sont accessibles gratuitement. En vous inscrivant, vous recevez des crédits offerts. Ces crédits vous permettent d'accéder à tout le contenu : le manuel complet, les centaines de codes prêts à l'emploi, les automatisations, et l'application de recherche de codes. IA Home permet aussi l'accès à d'autres ressources indispensables : QR codes dynamiques, outils IA (détection de texte généré par IA, transcription audio Whisper, analyse de PDF), transferts de fichiers sans cloud (PsiTransfer), et bien d'autres. Rien à payer si vous restez dans le cadre des crédits offerts.

Petit rappel pour les débutants : une carte est un bloc visuel de votre tableau de bord — un bouton, une jauge, un graphique — qui affiche ou contrôle vos appareils. Une automatisation est une règle qui exécute des actions toute seule selon des conditions : par exemple allumer la lumière au coucher du soleil, ou envoyer une alerte si une porte reste ouverte.

On commence par les nouveautés, puis je vous fais une démo détaillée de deux éléments : l'automatisation « réveil progressif » et la carte Flex Cells Card.

3. Démo 1 — Automatisation « Réveil progressif » (1:30 – 3:00)

L'automatisation « réveil progressif », ou simulation d'aube, consiste à faire monter progressivement la luminosité d'une lampe le matin, sur environ 30 minutes, pour un réveil plus doux.

[Afficher l'application de recherche de codes]

  • On va dans les Templates & Automatisations.
  • On cherche « réveil ».
  • On ouvre la carte « Réveil progressif (simulation aube) ».

[Montrer le code YAML]

L'idée :

  • Un déclencheur à heure fixe, par exemple 6 h 30.
  • Une séquence répétée : à chaque minute, on augmente la luminosité de 3 % avec une transition douce.
  • Sur 30 minutes, ça donne une montée progressive de 0 à environ 90 %.

À adapter chez vous :

  • L'heure de réveil dans le trigger.
  • L'entité de la lumière de la chambre.
  • Si vous utilisez un input_datetime pour l'heure, vous remplacez l'heure fixe par cette entité.

[Montrer rapidement le chemin dans Home Assistant si possible : Paramètres → Automatisations → Créer une automatisation → Modifier en YAML]

Ça change vraiment le réveil, surtout l'hiver.

4. Démo 2 — Flex Cells Card (3:00 – 4:30)

La Flex Cells Card est une carte HACS qui permet de créer des tableaux personnalisés avec des colonnes de texte, d'icônes et d'entités.

[Afficher la carte dans l'application]

  • Section Cartes HACS Populaires (2026).
  • On choisit Flex Cells Card — Tableaux flexibles (2026).

[Montrer le code YAML]

Structure typique :

  • Une ligne d'en-tête avec les titres : Pièce, Température, Humidité.
  • Une ou plusieurs lignes de données : une cellule texte (Salon), puis deux cellules entité (température, humidité).

Atouts pour les débutants :

  • Éditeur visuel intégré : pas besoin de tout saisir en YAML.
  • Tri par colonne.
  • Colonnes responsives.
  • Règles dynamiques (couleurs selon des seuils, par exemple).

À personnaliser :

  • Remplacer sensor.temperature_salon et sensor.humidite_salon par vos propres entités.
  • Ajouter d'autres pièces ou lignes en copiant le bloc cells.
  • Après installation via HACS, le code se colle dans une carte « Code éditeur » du tableau de bord Lovelace.

# Son du compte à rebours

Placez ici les fichiers audio du décompte :
- **countdown.mp3** : décompte 5 ou 8 secondes
- **countdown2.mp3** : décompte 3 secondes (option sélectionnée dans le menu)

## Spécifications recommandées

- **Format** : MP3 (compatible tous navigateurs)
- **Durée** : 8 secondes (ou adapté au countdown)
- **Ambiance** : Festive, mariage, événement — décompte audible et engageant

## Où trouver / créer votre son

- **Freesound.org** : "countdown", "party countdown", "New Year countdown" (licence CC)
- **Pixabay / Mixkit** : Musique et SFX libres de droits
- **Audacity** : Monter une voix + fond festif, ou créer un décompte rythmé
- **IA vocale (ElevenLabs, etc.)** : Générer "8, 7, 6, 5..." avec une intonation joyeuse

## Alternative

Si aucun fichier n'est présent, le compte à rebours s'affiche visuellement uniquement (aucune erreur).
